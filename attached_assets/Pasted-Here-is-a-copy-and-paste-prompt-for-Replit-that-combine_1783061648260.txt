The Credit Narrative currently displays incorrect percentages because decimal ratios are being multiplied twice.

inside the dashboard

but inside the narrative it becomes

5990%

which is incorrect.

Other examples include:

62% → 6200%

58.3% → 5833%

66.7% → 6667%

-30% → -3000%

The dashboard values are correct.

Only the narrative generation is incorrect.

Required Fix

Audit every percentage inserted into the Credit Narrative.

Wherever percentages are inserted into text:

Executive Summary

Financial Strength

Revenue Quality

Expense Structure

Volatility

Trend

Governance Commentary

Recommendation

use the already formatted percentage value.

Do NOT multiply by 100 again.

If the value already equals:

59.9

display

59.9%

NOT

5990%.

Apply this consistently throughout the Narrative Engine.
